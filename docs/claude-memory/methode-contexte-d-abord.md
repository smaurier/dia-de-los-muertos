Sylvain construit le jeu en deux phases : d'abord tout le **contexte** (la maison pièce par pièce, portes, mobilier, personnages placés — ex. enfants figés debout sur les chaises, roaming désactivé « pour le moment »), puis le **scénario** quand le contexte sera nickel.

**Why :** les mécaniques narratives (idles, scénarios NPC, arcs) seront posées sur un décor stabilisé — éviter de régler deux choses mouvantes à la fois.

**How to apply :** pendant cette phase, ne pas proposer de travail scénario/narration ; prioriser géométrie, textures, collisions, placement. Les scénarios NPC désactivés (consts conservées dans familyConfig) seront réactivés plus tard. Une pièce à la fois, validation visuelle — voir [[lecon-multi-pieces]] et [[sylvain-contexte]].
